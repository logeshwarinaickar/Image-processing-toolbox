# 🧰 Image Processing Toolbox

A visually interactive web application built using **Streamlit** that allows users to analyze, process, and extract insights from images — all in one place.

---

## 🚀 Features

- 🎨 **Filters & Effects**
  - Grayscale
  - Gaussian Blur
  - Edge Detection

- 🙂 **Face Detection**
  - Detects faces using OpenCV Haar Cascade

- 🌈 **Color Palette Generator**
  - Extracts dominant colors from the image
  - Displays RGB values with dynamic UI

- 📊 **Image Analysis Dashboard**
  - RGB Histogram
  - Brightness Distribution
  - Smart Image Summary (Dark / Bright / Balanced)

- ⬇️ **Download & Export**
  - Download processed images
  - Download full image analysis report
